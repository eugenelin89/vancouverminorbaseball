# Prompt Registry

This folder stores reusable project prompts.

## Naming Rule

- Each prompt is stored as a Markdown file.
- Prompt filenames use the format `[new app name]_prompt_[id].md`.
- The app name portion should be lowercase and use underscores if needed.
- IDs start at `0` and increase by `1` for each new prompt.
- Do not rename existing prompt files after they are created.
- When creating a new prompt, use the next unused integer ID.

Examples:

- `analytics_prompt_0.md`
- `analytics_prompt_1.md`
- `league_reports_prompt_2.md`
