# Analytics Prompts

This folder stores reusable Codex prompts for planning, implementing, reviewing, and fixing Analytics implementation phases.

Prompts in this folder should reference the Architecture Handbook and the relevant Implementation Handbook phase document instead of restating architecture.

Recommended workflow:

1. Plan phase.
2. Implement phase.
3. Review phase.
4. Apply approved fixes.
5. Update the phase review and `docs/analytics/implementation/STATUS.md`.

Do not implement multiple phases from a single prompt unless explicitly instructed.
